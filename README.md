# 京师学林 · 北师大中文系学者库

北师大中文系学人师承与学术脉络的静态网站，数字人文课程作业。

在线访问：<https://sitting-forgetting.github.io/bnu-scholars/>

## 页面

| 页面 | 内容 |
|---|---|
| `index.html` | 首页 |
| `masters.html` | 先贤名师 |
| `map.html` | 学人地图 |
| `lineage.html` | 师承世表 |
| `network.html` | 师承网络 |
| `timeline.html` | 时间线 |
| `taxonomy.html` | 分类体系 |
| `detail.html` | 学者详情 |
| `build-guide.html` | 构建说明 |
| `data-sources.html` | 数据来源 |

## 说明

- 纯静态站点：`css/`、`js/`、`data/`、`fonts/`、`vendor/` 均为本地资源，可离线打开 `index.html`
- 学人地图底图使用天地图，需要联网；生产代码不含 Key
